Enterprise Architecture & SaaS Dashboard Overview ​

Slicemeter uses a dual-engine architecture designed to support both Cloud SaaS and 100% Enterprise Air-Gapped deployments.

Enterprise Dashboard Visual Interface ​

1. Cost Explorer & Multi-Cluster Chargeback Ledger ​

The Cost Explorer provides real-time visibility into GPU spend, token intercept costs, allocated GPU-hours, and estimated waste across multi-cloud Kubernetes clusters (AKS, EKS, GKE, and local Kind).

Key Capabilities: ​

  • Memory-Weighted Proportional Attribution: Maps nvidia.com/gpu allocation and DCGM VRAM usage directly to namespaces.
  • LLM Token Chargeback: Tracks prompt and completion tokens for OpenAI, Ollama, and vLLM inference workloads.
  • 1-Click Audit Exports: Generates executive PDF and CSV chargeback invoices for finance teams.

2. Cost Optimization & Waste Detection Engine ​

Slicemeter continuously monitors CUDA kernel calls, VRAM allocations, and CPU utilization to detect idle GPU allocations and unoptimized cloud tiers.

Automated Recommendations: ​

  • Zero-GPU-Utilization Pods: Identifies pods requesting GPUs but recording 0% CUDA load for consecutive hours.
  • On-Demand to Spot Migration: Recommends Spot instance migration for workloads running on on-demand nodes with low average utilization.
  • Token Spike Caching: Detects redundant LLM prompt requests and suggests sidecar cache deduplication.

3. Settings & Stripe Enterprise Subscription Billing ​

Manage cluster agent ingestion keys, view active license tiers, and upgrade enterprise SaaS subscriptions.

4. Zero-Overhead Spend Forecasting Engine ​

Slicemeter includes a native, CPU-friendly time-series forecasting engine that predicts month-end GPU spend and token consumption without requiring external ML Python runtimes or heavy compute infrastructure.

Highlights: ​

  • Zero Compute Cost (0.01ms CPU): Native Go standard library math execution; runs in nanoseconds with zero GPU/VRAM footprint.
  • Holt's Double Exponential Smoothing: Measures baseline hourly spend rates ($\ell_t$) and acceleration trends ($b_t$) to project month-end budgets with $95%$ statistical confidence intervals ($\pm 8%$).
  • Early Budget Overrun Warnings: Highlights projected budget overruns weeks before they occur so FinOps teams can adjust resource limits proactively.

Enterprise Authentication & Access Control ​

Slicemeter provides enterprise-grade authentication options designed for modern security compliance:

  • WebAuthn & Passkeys: Biometric authentication (Apple TouchID, FaceID, Windows Hello) and hardware security keys (YubiKey) for passwordless access.
  • Enterprise SSO & SAML/OIDC: Seamless integration with Okta, Microsoft Entra ID (Azure AD), Google Workspace, and Keycloak.
  • Automated Tenant Onboarding: Instant cluster API key provisioning upon subscription.

Technical Architecture Stack ​

  • In-Cluster Agent: Go, Prometheus DCGM Collector, eBPF Uprobes (cilium/ebpf), BadgerDB embedded store.
  • Proxy & Webhook: Token sidecar reverse proxy + Mutating Admission Webhook controller.
  • Control Plane API Server: Go HTTP REST server with dual SQLite / PostgreSQL telemetry persistence.
  • Dashboard UI: Next.js 16, TypeScript, Tailwind CSS, Recharts.
