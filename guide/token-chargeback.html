LLM Token Chargeback & TeamBudget CRD Governance ​

Slicemeter provides transparent LLM token metering and budget enforcement for Kubernetes workloads using an optional mutating webhook sidecar proxy and custom resources (TeamBudget CRD).

1. Automatic Sidecar Injection (slicemeter.io/inject-sidecar) ​

When sidecar injection is enabled (webhook.enabled: true) and you label a namespace or pod for token chargeback metering, the Slicemeter Mutating Webhook injects a lightweight proxy container into the pod. The proxy inspects HTTP payload headers and response streams to calculate input/output token counts without requiring application code changes.

Step 1: Enable Namespace Auto-Injection ​

yaml
apiVersion: v1
kind: Namespace
metadata:
 name: team-ai
 labels:
 slicemeter.io/inject-sidecar: "true"

Step 2: Or Annotate Pod Spec Directly ​

yaml
apiVersion: apps/v1
kind: Deployment
metadata:
 name: ollama-llama3
 namespace: team-ai
spec:
 template:
 metadata:
 annotations:
 slicemeter.io/inject-sidecar: "true"
 slicemeter.io/model-pricing: "0.002" # $0.002 per 1M tokens
 spec:
 containers:
 - name: ollama
 image: ollama/ollama:latest
 ports:
 - containerPort: 11434

3. Configuring TeamBudget CRDs ​

You can define budget rules per namespace using the TeamBudget Custom Resource Definition (CRD). The in-cluster Slicemeter agent watches these CRDs and triggers multi-channel webhooks upon breach.

Example: TeamBudget Manifest (teambudget-team-ai.yaml) ​

yaml
apiVersion: finops.slicemeter.io/v1alpha1
kind: TeamBudget
metadata:
 name: team-ai-monthly-cap
 namespace: team-ai
spec:
 monthlyLimitUSD: 1000.00
 currency: "USD"
 alertThresholdsPct:
 - 80 # Warning alert dispatched to Slack & Email at $800
 - 100 # Critical alert dispatched to PagerDuty & Slack at $1,000
 notifications:
   slackWebhookUrl: "https://hooks.slack.com/services/T00/B00/XXXXX" # Or use slackWebhookSecret for K8s Secret reference
   pagerdutyKey: "pd-events-v2-routing-key"                           # Or use pagerdutyKeySecret for K8s Secret reference
   teamsWebhookUrl: "https://company.webhook.office.com/..."
   emailRecipients:
     - "finops@company.com"
     - "lead-ai-eng@company.com"
 enforcementAction: "SoftThrottle" # Options: AlertOnly | SoftThrottle

4. Enforcement Action Modes (enforcementAction) ​

Enforcement ModeAction on Budget BreachRBAC & Security Impact
AlertOnly (Default)Dispatches Slack Block-Kit, Teams Adaptive Cards, PagerDuty, and Email alerts with copyable remediation commands.100% Read-Only RBAC. Zero workload mutation.
SoftThrottleIntercepts new inference API requests (/v1/chat/completions) and returns HTTP 429 (rate_limit_exceeded) rate-limiting payloads.Evaluated locally inside the sidecar proxy. No cluster API write access required.

Apply to Cluster: ​

bash
kubectl apply -f teambudget-team-ai.yaml

Inspect Active Team Budgets: ​

bash
kubectl get teambudgets -n team-ai

Output:

NAME                 LIMIT    CURRENCY   ENFORCEMENT    STATUS
team-ai-monthly-cap  1000.00  USD        SoftThrottle   OK (76%)

5. Token Spike Caching & Sidecar Deduplication ​

In production AI microservices and RAG pipelines, applications frequently send duplicate system prompts and long context documents. Without caching, LLM engines re-compute identical tokens repeatedly, driving up GPU VRAM load and API costs.

How End Users Use Token Spike Caching: ​

  • Zero-Touch Detection (Default): Detection runs automatically out-of-the-box when the sidecar proxy is active (slicemeter.io/inject-sidecar: "true"). No configuration or feature flags are required by engineers.
  • 1-Click Sidecar Cache Annotation: When a recommendation is triggered in the Cost Explorer dashboard, developers can enable exact-match caching on the Slicemeter proxy sidecar by adding a single annotation to their pod spec:
    yaml
    metadata:
  annotations:
    slicemeter.io/enable-cache: "true"
  • Application Level Options: Alternatively, engineers can enable vLLM prefix caching (--enable-prefix-caching) or deploy a local Redis caching sidecar (gptcache) to serve cached responses in < 5ms with 0 GPU compute cost.
