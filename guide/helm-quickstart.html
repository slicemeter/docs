Helm Quickstart Guide ​

Deploying Slicemeter Agent to Kubernetes

1. Cloud SaaS Mode ​

If you are subscribing to Slicemeter Cloud SaaS (slicemeter.com), deploy only the lightweight telemetry agent to your cluster:

Where to get your Cluster API Key: API keys (plk_live_...) are automatically issued to your organization upon registering on the Slicemeter SaaS Control Plane (app.slicemeter.com). You can view and copy your keys under ⚙ Settings & API Keys -> Agent License Keys.

Option A: OCI Direct Install (Recommended — No helm repo add required) ​

bash
helm install slicemeter oci://ghcr.io/slicemeter/helm/slicemeter \
  --namespace slicemeter-system \
  --create-namespace \
  --set saas.apiKey="YOUR_CLUSTER_API_KEY" \
  --set saas.endpoint="https://api.slicemeter.com"

Option B: Traditional helm repo add ​

bash
helm repo add slicemeter https://slicemeter.github.io/helm-charts
helm repo update

helm install slicemeter slicemeter/slicemeter \
  --namespace slicemeter-system \
  --create-namespace \
  --set saas.apiKey="plk_live_9f82a17b4c6e0012a88371192" \
  --set saas.endpoint="https://api.slicemeter.com"

The agent will run eBPF uprobes, scrape GPU/DCGM metrics, intercept token sidecars, and stream telemetry to your Slicemeter Control Plane.

2. Enterprise Air-Gapped Mode ​

For banks, healthcare providers, and defense contractors running in isolated, air-gapped data centers with 0 internet egress:

Strict Air-Gapped Guarantee: The Enterprise On-Premise build disables all external HTTP calls (including Stripe API, public CDN assets, and cloud endpoints). All billing is handled offline via annual purchase orders / invoices.

Step 1: Install Enterprise License Secret ​

bash
kubectl create namespace slicemeter-system

kubectl create secret generic slicemeter-license \
 --namespace slicemeter-system \
 --from-file=license.lic=./slicemeter-enterprise.lic

Step 2: Deploy Full Self-Hosted Stack via Helm ​

bash
helm install slicemeter-control-plane ./helm/slicemeter-control-plane \
 --namespace slicemeter-system \
 --set license.secretName="slicemeter-license" \
 --set auth.type="oidc" \
 --set auth.oidc.issuerUrl="https://sso.internal.company.com"

3. Prometheus & Grafana-Free Options ​

Slicemeter does NOT require a pre-existing Prometheus or Grafana installation in your cluster.

Option A: Built-in Passive eBPF Direct-Scraping (Default) ​

Slicemeter includes an embedded, lightweight eBPF and DCGM collector daemonset that attaches directly to libcudart.so and the host NVIDIA GPU driver. It collects all metrics passively without needing Prometheus.

Option B: Bundled Prometheus Stack via Helm (1 Command) ​

If you want Prometheus metrics collected automatically without managing a separate stack, enable Slicemeter's bundled monitoring dependency during Helm installation:

bash
helm install slicemeter oci://ghcr.io/slicemeter/helm-charts/slicemeter \
  --set prometheus.embed=true

Option C: Enterprise cert-manager.io Webhook TLS Integration ​

For clusters with cert-manager deployed, enable native cert-manager.io/v1 Certificate and Issuer generation instead of the default self-signed cert init job:

bash
helm install slicemeter oci://ghcr.io/slicemeter/helm/slicemeter \
  --set webhook.enabled=true \
  --set webhook.certManager.enabled=true

Option D: Native Slicemeter Dashboard UI (No Grafana Needed) ​

You do NOT need Grafana to view GPU cost breakdowns or token chargeback reports. Slicemeter includes its own enterprise Control Plane UI (app.slicemeter.com or self-hosted) with real-time charts, cost allocation tables, budget alerts, and executive PDF exports.
