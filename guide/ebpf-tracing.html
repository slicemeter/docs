v1.0.0 - Production Release

On this page

eBPF CUDA Precision Mode ​

Slicemeter attaches eBPF uprobes directly to cudaLaunchKernel and cudaMalloc in libcudart.so.

How It Works ​

  1. Uprobes: Intercepts kernel entry/exit timestamps.
  2. Ring Buffer: Streams struct cuda_event payloads to the Go agent.
  3. PID-to-Pod Resolver: Inspects /proc/<pid>/cgroup to map process IDs to Kubernetes container IDs.
